== 1. Introduction

Chronicle Core defines a set of small "value" interfaces that model primitive fields or arrays of primitives.
These interfaces, found in the `net.openhft.chronicle.core.values` package, are designed to allow direct manipulation of memory regions, such as memory-mapped files or off-heap buffers.
This approach enables reading and writing data like `long`s, `int`s, or `String`s without the overhead of creating intermediate Java wrapper objects for each access.

Implementations of these interfaces (often found in higher-level Chronicle libraries like Chronicle Bytes) typically operate on raw memory addresses using Chronicle Core's `Memory` API.

The available value interfaces include:

* `BooleanValue`
* `ByteValue`
* `CharValue`
* `ShortValue`
* `IntValue` (also `java.io.Closeable`)
* `LongValue` (also `java.io.Closeable`)
* `FloatValue`
* `DoubleValue`
* `StringValue`
* `TwoLongValue` (extends `LongValue`)
* `IntArrayValues` (also `java.io.Closeable`)
* `LongArrayValues` (also `java.io.Closeable`)

== 2. Scalar Value Interfaces

These interfaces represent a single mutable value.

=== 2.1. `BooleanValue`
Represents a single boolean value.
* **Key Methods**:
** `boolean getValue()`
** `void setValue(boolean value)`

[source,java]
----
 BooleanValue bv = /* implementation provided by another library */;
 bv.setValue(true);
 boolean state = bv.getValue();
----

=== 2.2. `ByteValue`
Represents a single 8-bit byte value.

* **Key Methods**:
** `byte getValue()`
** `void setValue(byte value)`
** `byte addValue(byte delta)`

=== 2.3. `CharValue`
Represents a single 16-bit char value.

* **Key Methods**:
** `char getValue()`
** `void setValue(char value)`

=== 2.4. `ShortValue`
Represents a single 16-bit short value.

* **Key Methods**:
** `short getValue()`
** `void setValue(short value)`
** `short addValue(short delta)`

=== 2.5. `IntValue`
Represents a single 32-bit integer value.
Implements `java.io.Closeable`.

* **Key Methods**:
** `int getValue()`
** `void setValue(int value)`
** `int getVolatileValue()`
** `void setOrderedValue(int value)`
** `int addValue(int delta)`
** `int addAtomicValue(int delta)`
** `boolean compareAndSwapValue(int expected, int value)`

=== 2.6. `LongValue`
`LongValue` represents a single 64-bit value.
Implements `java.io.Closeable`.
In addition to normal get and set methods, it provides atomic operations and ordered writes for concurrent access scenarios.

* **Key Methods**:
** `long getValue()`
** `void setValue(long value)`
** `long getVolatileValue()` / `getVolatileValue(long closedValue)`
** `void setVolatileValue(long value)`
** `void setOrderedValue(long value)`
** `long addValue(long delta)`
** `long addAtomicValue(long delta)` (typically delegates to `addValue` or provides stronger atomicity)
** `boolean compareAndSwapValue(long expected, long value)`
** `void setMaxValue(long value)` / `void setMinValue(long value)`

[source,java]
----
// Assuming LongValueImpl is a concrete implementation
LongValue value = new LongValueImpl(); // Example from test
value.setValue(42L);
long current = value.getValue();
boolean swapped = value.compareAndSwapValue(42L, 100L);
----

=== 2.7. `FloatValue`
Represents a single 32-bit float value.

* **Key Methods**:
** `float getValue()`
** `void setValue(float value)`
** `float getVolatileValue()`
** `void setOrderedValue(float value)`
** `float addValue(float delta)`
** `float addAtomicValue(float delta)`

=== 2.8. `DoubleValue`
Represents a single 64-bit double value.
* **Key Methods**:
** `double getValue()`
** `void setValue(double value)`
** `double getVolatileValue()`
** `void setOrderedValue(double value)`
** `double addValue(double delta)`
** `double addAtomicValue(double delta)`

=== 2.9. `StringValue`
`StringValue` models a mutable String, often stored in direct memory.

* **Key Methods**:
** `String getValue()`
** `void setValue(@MaxBytes CharSequence value)`: Sets the string. The `@MaxBytes` annotation can be used by implementations to enforce a maximum encoded size (see section below).
** `StringBuilder getUsingValue(StringBuilder stringBuilder)`: Copies the value into a supplied `StringBuilder` to potentially avoid new String allocations.

[source,java]
----
 StringValue sv = /* implementation supplied by Chronicle Bytes or similar */;
 sv.setValue("example");
 String text = sv.getValue();
 StringBuilder sb = new StringBuilder();
 sv.getUsingValue(sb);
 assert "example".contentEquals(sb);
----

=== 2.10. `TwoLongValue`
`TwoLongValue` extends `LongValue` to represent a pair of 64-bit values.
It inherits all methods for the first long value and adds corresponding methods for the second.

* **Key Additional Methods**:
** `long getValue2()`
** `void setValue2(long value2)`
** `long getVolatileValue2()`
** `void setVolatileValue2(long value)`
** `void setOrderedValue2(long value)`
** `long addValue2(long delta)`
** `long addAtomicValue2(long delta)`
** `boolean compareAndSwapValue2(long expected, long value)`

== 3. Array Value Interfaces

These interfaces provide a typed view over an array of primitive values, often in direct memory.
They implement `java.io.Closeable`.

=== 3.1. `IntArrayValues`
Represents an array of 32-bit integer values.

* **Key Methods**:
** `long getCapacity()`
** `long getUsed()` / `void setMaxUsed(long usedAtLeast)`
** `int getValueAt(long index)`
** `void setValueAt(long index, int value)`
** `int getVolatileValueAt(long index)`
** `void setOrderedValueAt(long index, int value)`
** `boolean compareAndSet(long index, int expected, int value)`
** `void bindValueAt(long index, IntValue value)` (binds a reusable `IntValue` to an element)
** `long sizeInBytes(long capacity)`
** `boolean isNull()` / `void reset()`

=== 3.2. `LongArrayValues`
`LongArrayValues` provides a typed view over an array of 64-bit long values.

* **Key Methods**:
** `long getCapacity()`
** `long getUsed()` / `void setUsed(long used)` / `void setMaxUsed(long usedAtLeast)`
** `long getValueAt(long index)`
** `void setValueAt(long index, long value)`
** `long getVolatileValueAt(long index)`
** `void setOrderedValueAt(long index, long value)`
** `boolean compareAndSet(long index, long expected, long value)`
** `void bindValueAt(long index, LongValue value)` (binds a reusable `LongValue` to an element)
** `long sizeInBytes(long capacity)`
** `boolean isNull()` / `void reset()`

[source,java]
----
 LongArrayValues la = /* implementation supplied by Chronicle Bytes */;
 long capacity = la.getCapacity();
 if (capacity > 0) {
     la.setValueAt(0, 123L);
     long first = la.getValueAt(0);
     assert first == 123L;
 }
 la.close(); // If it's Closeable
----

== 4. `@MaxBytes` Annotation

The `@MaxBytes` annotation can be applied to parameters of methods, particularly in interfaces like `StringValue`, to indicate the maximum number of encoded bytes allowed for a variable-length data type.
Implementations can use this information to enforce size limits.

[source,java]
----
public interface MyStringStorage {
    // Implementations should ensure 'data' doesn't exceed 64 bytes when encoded
    void storeString(@MaxBytes(64) CharSequence data);
}
----

== 5. Mapping to Direct Memory

Concrete implementations of these value interfaces, often found in libraries like Chronicle Bytes, use the `Memory` API from Chronicle Core (`OS.memory()`) to operate on raw memory addresses.
This allows them to directly manipulate off-heap memory or memory-mapped file regions.

The following example illustrates the low-level operations an implementation might use:
[source,java]
----
 try (RandomAccessFile raf = new RandomAccessFile("data.bin", "rw")) { // File operations for context
     FileChannel fc = raf.getChannel();
     long regionSize = 64; // Bytes
     long address = OS.map(fc, FileChannel.MapMode.READ_WRITE, 0, regionSize); // Get native address
     try {
         Memory memory = OS.memory();
         // A LongValue implementation could wrap 'address' and 'memory'
         // For example, LongValue.setValue(long) could do:
         memory.writeLong(address, 12345L);
         // And LongValue.getValue() could do:
         long val = memory.readLong(address);
         System.out.println(val);
     } finally {
         OS.unmap(address, regionSize);
     }
 } catch (IOException e) {
     e.printStackTrace();
 }
----
