= System Properties Overview
[[system-properties]]

Chronicle-Core recognises a variety of system properties to tune behaviour at runtime.
Properties may be supplied on the command line with `-D` or loaded from a
link:jvm-and-os-utilities.adoc#loading-system-properties[`system.properties` file].

`Jvm.getBoolean()` considers a property `true` when it is present with no value, set to `true` or set to `yes`.
Any other value is treated as `false`.

== Startup hooks
[cols="1,1,3,1,1",options="header"]
|===
| Key | Default | Description | Valid Values | Variable
| `chronicle.init.runnable` | | Run before Chronicle reads any properties. | Fully qualified class name | `CHRONICLE_INIT_CLASS`
| `chronicle.postinit.runnable` | | Run after `Jvm` static initialisation. | Fully qualified class name | `CHRONICLE_POSTINIT_CLASS`
|===

== Debugging & Tracing
[cols="1,1,3,1,1",options="header"]
|===
| Key | Default | Description | Valid Values | Variable
| `chronicle.analytics.disable` | `false` | Disable analytics reporting. | boolean | -
| `chronicle.announcer.disable` | `false` | Turn off announcer logging. | boolean | `DISABLE_ANNOUNCEMENT`
| `debug` | `false` | JVM is running under a debugger. | boolean | `IS_DEBUG`
| `debug.adding.handlers` | `false` | Log handler registration. | boolean | `DEBUG_ADDING_HANDLERS`
| `disable.debug.info` | `false` | Suppress debug level logging. | boolean | `DISABLE_DEBUG`
| `disable.perf.info` | `false` | Suppress performance level logging. | boolean | -
| `disable.resource.warning` | `false` | Suppress resource tracing warnings. | boolean | -
| `jfr` | `false` | JVM is running with Flight Recorder. | boolean | `IS_FLIGHT_RECORDER`
| `jvm.resource.tracing` | `false` | Enable resource tracing of allocations. | boolean | `RESOURCE_TRACING`
| `jvm.safepoint.enabled` | `false` | Insert low-cost JVM safepoints. | boolean | `SAFEPOINT_ENABLED`
| `report.unoptimised` | `false` | Warn when unoptimised methods are used. | boolean | `REPORT_UNOPTIMISED`
|===

== Resource Management
[cols="1,1,3,1,1",options="header"]
|===
| Key | Default | Description | Valid Values | Variable
| `background.releaser` | `true` | Queue heavy cleanup to a background thread. | boolean | `BG_RELEASER`
| `background.releaser.thread` | `true` | Start the background releaser thread. | boolean | `BG_RELEASER_THREAD`
| `closeable.warn.secs` | `0.02` | Threshold before warning about slow `close()`. | decimal seconds | `WARN_NS`
| `disable.discard.warning` | `true` | Suppress warnings when objects are discarded. | boolean | `DISABLE_DISCARD_WARNING`
| `disable.single.threaded.check` | `false` | Turn off thread ownership checks. | boolean | `DISABLE_SINGLE_THREADED_CHECK`
| `reference.warn.count` | `Integer.MAX_VALUE` | Emit a warning once the reference count reaches this level. | integer | `WARN_COUNT`
| `reference.warn.secs` | `0.003` | Threshold before warning about slow release. | decimal seconds | `WARN_NS`
| `warnAndCloseIfNotClosed` | `true` | Automatically close leaked resources at shutdown. | boolean | -
| `chronicle.core.mmap.allowedDirs` | | Whitelist of directories for memory mapping. | comma-separated paths (empty = unrestricted) | -
| `system.properties` | `system.properties` | External file to load system properties. | file path | `SYSTEM_PROPERTIES`
| `chronicle.stringBuilderPool.instancesPerThread` | `4` | Size of the per-thread `StringBuilder` pool. | integer | `DEFAULT_STRING_BUILDER_POOL_SIZE_PER_THREAD`
|===

== Performance Tuning
